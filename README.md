# Kedai-Segara
Kedai Segara Ivana

Sistem manajemen stok, kasir, dan rekap harian untuk Kedai Segara Ivana berbasis **Google Apps Script** dan **Google Sheets**.

## Fitur Utama
- **Frontend Web App (`index.html`)**: Antarmuka responsif ramah tablet/mobile untuk operasional kasir, stok masuk, pengambilan bahan, dan rekap harian.
- **Backend Apps Script (`Kode.gs`)**: Logika bisnis, otentikasi PIN admin, lock concurrency, migrasi skema tabel, dan pencatatan riwayat transaksi langsung ke Google Sheets.
- **Tanpa Biaya Hosting**: Sepenuhnya berjalan di infrastruktur Google Workspace / Google Drive gratis.
