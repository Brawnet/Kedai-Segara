Panduan Pemasangan Stok Segara ke Spreadsheet Kosong

Mulai langsung dari pembuatan spreadsheet dan penyalinan 3 file utama
📦 Lokasi Berkas yang Digunakan:

Folder: E:\Kerja\Segara\apps-script (Hanya 3 file ini yang Anda butuhkan):

  • 📁 Kode.gs — Seluruh logika backend & sistem database Google Sheets
  • 📁 index.html — Tampilan web app mandiri untuk tablet & admin (siap pakai)
  • 📁 appsscript.json — Setelan manifes Apps Script (zona waktu Makassar / WITA & hak akses)

🚀 Langkah Demi Langkah Pemasangan

1 Buka Google Spreadsheet Baru (Kosong)
  1. Buka tautan sheets.new di browser Anda (atau buat spreadsheet baru di Google Drive).
  2. Ganti judul spreadsheet di kiri atas, contoh: Database Stok Kedai Segara.
  3. Biarkan lembar kerja dalam kondisi kosong.
2 Buka Menu Apps Script
  1. Pada bilah menu atas Google Sheets, klik: Ekstensi (Extensions) → Apps Script.
  2. Tab editor baru akan terbuka. Ganti nama proyek di kiri atas (tulisan "Untitled project") menjadi Stok Segara Backend, lalu klik Rename.
3 Salin 3 Berkas ke Apps Script

A. File Kode.gs

  1. Klik file default Code.gs di panel sebelah kiri editor.
  2. Hapus semua isinya (tekan Ctrl + A lalu Delete).
  3. Buka file apps-script/Kode.gs dari komputer Anda (bisa dengan Notepad). Salin semua isinya (Ctrl + A → Ctrl + C) lalu tempel ke editor (Ctrl + V).

B. File index.html

  1. Di samping tulisan Files di panel kiri, klik tombol + → pilih HTML.
  2. Beri nama file: index (cukup tulis index tanpa ekstensi .html) lalu tekan Enter.
  3. Hapus isi bawaannya. Buka file apps-script/index.html di komputer, salin semua isinya, lalu tempel ke editor.

C. File appsscript.json (Manifes)

  1. Klik ikon gerigi ⚙️ (Project Settings / Setelan Proyek) di bilah navigasi paling kiri.
  2. Beri centang pada: Show "appsscript.json" manifest file in editor.
  3. Kembali ke Editor dengan klik ikon < > di kiri atas.
  4. Klik file appsscript.json yang sekarang muncul di daftar file.
  5. Hapus isinya dan ganti dengan isi dari file apps-script/appsscript.json.
  6. Tekan Ctrl + S untuk menyimpan semua berkas.
4 Jalankan Fungsi Setup (Membangun Database)
  1. Di bilah atas editor Apps Script (sebelah tombol Run/Jalankan), klik dropdown pilihan fungsi dan pilih: setup.
  2. Klik tombol Run (Jalankan).
  3. Muncul pop-up otorisasi izin (Authorization required):
    • Klik Review permissions.
    • Pilih akun Google Anda.
    • Jika muncul peringatan Google hasn't verified this app, klik Advanced (Lanjutan) di kiri bawah.
    • Klik tautan Go to Stok Segara Backend (unsafe).
    • Klik tombol Allow (Izinkan).
  4. Tunggu beberapa saat sampai muncul notifikasi "Execution completed".
✅ Spreadsheet Otomatis Terbentuk!
Buka kembali spreadsheet Anda. Seluruh sheet database kini sudah lengkap terbentuk otomatis: Barang, Karyawan, Transaksi, Rekap, RekapBaris, Opname, Pengaturan, dan Log_Login.
5 (Opsional) Impor Master Barang Kedai Segara

Jika ingin langsung memasukkan daftar 100+ master bahan Segara (kopi, susu, sirup, cup, dll.):

  1. Pada dropdown fungsi, pilih: imporDataSegara.
  2. Klik tombol Run dan tunggu hingga selesai. Seluruh barang akan otomatis masuk ke tabel Barang dengan stok awal 0.
6 Deploy Menjadi Web App (Link Aplikasi)
  1. Di pojok kanan atas, klik tombol biru Deploy → New deployment.
  2. Klik ikon gerigi ⚙️ di samping Select type → pilih Web app.
  3. Atur kolomnya:
    • Description: Stok Segara Final
    • Execute as: Me (email Anda)
    • Who has access: Anyone (Siapa saja)
  4. Klik tombol Deploy.
  5. Salin Web app URL yang muncul (berakhiran /exec).

📱 Penggunaan Aplikasi

Mode URL Akses Fungsi
Mode Tablet (Dapur / Kasir) https://script.google.com/macros/s/.../exec Karyawan input ambil bahan, terima barang supplier, dan rekap closing sisa dapur.
Mode Admin (Owner / Manager) https://script.google.com/macros/s/.../exec?mode=admin
(atau tekan tombol Admin di pojok kanan atas)		 Login OTP email & buat PIN pribadi. Mengelola stok, opname fisik, barang, staf, dan laporan.

🔄 Cara Update di Kemudian Hari

  1. Salin isi file terbaru ke Apps Script lalu simpan (Ctrl + S).
  2. Klik menu Deploy → Manage deployments.
  3. Klik ikon pensil ✏️ (Edit) → ubah Version menjadi New version → klik Deploy.
  4. Link URL Web App tidak berubah dan seluruh perangkat langsung terupdate.
